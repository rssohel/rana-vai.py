# Network Checker Tool

Simple Python-based network status checker.

## Features
- Check if a server is online
- Simple and fast
- Works on Termux / Linux / Windows

## Installation (Termux)

pkg update
pkg install python -y
pip install -r requirements.txt

## Run

python rana-vai.py
